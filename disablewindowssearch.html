Windows 11 Tweaks

Disable Web Search in Start Menu

Copy and paste this into PowerShell:


# Define the registry path
$regPath = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Search"

# Create the registry key if it doesn't exist
if (-not (Test-Path $regPath)) {
    New-Item -Path $regPath -Force
}

# Set the required values
New-ItemProperty -Path $regPath -Name "BingSearchEnabled" -PropertyType DWord -Value 0 -Force
New-ItemProperty -Path $regPath -Name "AllowSearchToUseLocation" -PropertyType DWord -Value 0 -Force
New-ItemProperty -Path $regPath -Name "CortanaConsent" -PropertyType DWord -Value 0 -Force

Write-Host "Registry keys successfully created or updated."
